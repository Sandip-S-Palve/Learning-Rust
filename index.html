Rust for the .NET Architect

🦀 Accurate as of 2026-10-11 · Rust 1.99.0 · Edition 2024

This course takes you from an experienced .NET solution architect to someone who can design, build and advise on Rust systems. You start with the computer-science foundations that .NET hides from you, then learn the language in depth, and finish by building two production-grade products: a pluggable rule engine and a durable workflow engine.
